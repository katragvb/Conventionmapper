# Security policy

## Supported versions

Security fixes are released for the latest minor version of `ConventionMapper` and `ConventionMapper.SourceGenerator`.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private vulnerability reporting instead: go to the repository's **Security** tab and choose **Report a vulnerability**.

Include what is affected, how to reproduce it and the impact you see. You will get a reply within a few days, and a fix or mitigation plan as soon as the problem is confirmed.
